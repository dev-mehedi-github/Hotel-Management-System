# 🏨 Hotel Management System

A desktop-based Hotel Management System built with Java Swing. It provides a centralized interface for managing hotel information, staff records, room availability, billing, and user accounts.

## ✨ Features
| Feature | Description | Developer |
|---------|-------------|-----------|
| 🖥️ **Dashboard** | Main navigation hub to access all modules | *(Assign)* |
| 🔍 **Hotel Search** | Retrieve hotel details by ID | *(Assign)* |
| 👥 **Staff Search** | View staff info, salary, and assigned hotel | *(Assign)* |
| 💳 **Payment/Bill Search** | Lookup billing records by Bill ID | *(Assign)* |
| 🛏️ **Room Search** | Check room cost, category, status, and hotel | *(Assign)* |
| 👤 **User Search** | Manage guest/user accounts | *(Assign)* |

## 🛠️ Tech Stack
- **Language**: Java 11+
- **GUI**: Java Swing & AWT
- **Database**: Oracle Database (JDBC)
- **Version Control**: Git & GitHub
