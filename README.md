# 🏨 Hotel Management System

A desktop-based Hotel Management System built with Java Swing. It provides a centralized interface for managing hotel information, staff records, room availability, billing, and user accounts.

## ✨ Features
| Feature | Description | 
|---------|-------------|
| 🖥️ **Dashboard** | Main navigation hub to access all modules | 
| 🔍 **Hotel Search** | Retrieve hotel details by ID | 
| 👥 **Staff Search** | View staff info, salary, and assigned hotel | 
| 💳 **Payment/Bill Search** | Lookup billing records by Bill ID | 
| 🛏️ **Room Search** | Check room cost, category, status, and hotel | 
| 👤 **User Search** | Manage guest/user accounts | 

## 🛠️ Tech Stack
- **Language**: Java 11+
- **GUI**: Java Swing & AWT
- **Database**: Oracle Database (JDBC)
- **Version Control**: Git & GitHub
